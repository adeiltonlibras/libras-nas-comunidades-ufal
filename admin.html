Sobre segurança

O token é armazenado apenas na memória desta aba (sessionStorage) e é apagado ao fechar o navegador. Ele nunca é enviado a outro servidor — a conexão é feita diretamente com a API do GitHub.

Use um token restrito a este repositório. Se desconfiar de vazamento, revogue-o imediatamente em github.com/settings/tokens.
