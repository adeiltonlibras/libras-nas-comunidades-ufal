# Libras nas Comunidades: Benedito Bentes 2


> Projeto de Extensão da Universidade Federal de Alagoas

---

## 🏛️ Sobre

Curso Básico de Libras – Nível I, promovido pela Faculdade de Letras da UFAL em parceria com a Assembleia de Deus em Benedito Bentes 3, com o objetivo de difundir a Língua Brasileira de Sinais em comunidades periféricas de Maceió.

---

## 📋 Dados do curso

| | |
|---|---|
| **Período** | 17/10/2026 a 23/01/2027 |
| **Aulas** | Aos sábados, 15h às 17h |
| **Carga-horária** | 40 horas |
| **Modalidade** | Presencial + Atividades Complementares |
| **Local** | Assembleia de Deus — Benedito Bentes 3, Maceió/AL |
